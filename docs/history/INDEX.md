# Documentation history

This folder preserves the ADRs and supporting guides from commit `33252fd`
before the documentation cleanup. It is a historical snapshot, not a task list
or a source of current implementation instructions. Relative links were adjusted
for relocation; the decisions and phase records are retained.

- [Historical ADRs](adr/): numbered records before the architecture transition.
- [Supporting guides](guides/): previous feature guides and phase logs, including
  the cancelled session, retired providers and old onboarding index.
- [Current documentation](../INDEX.md): the starting point for development.
- [Current decisions](../adr/): the accepted transition and maintenance policy.

Some old code references describe files that have since been removed. Read
history to understand a decision, then verify the current source and guides.
Do not copy an old implementation or revive a cancelled plan from this folder.
New work updates the current guides; it does not append to these snapshots.
